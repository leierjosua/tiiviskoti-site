# Stock-/kuvituskuvat

Ulkopuoliset kuvituskuvat (esim. Unsplash) — **eivät firman omia kohteita**.
Käytetään tunnelmakuvituksena. Älä esitä näitä "oikeina asiakaskohteina".

- `photo-couple.jpg` — muutto/stressittömyys (tunnelma)
- `photo-clean-counter.jpg`, `photo-clean-sink.jpg` — puhtaat pinnat
- `photo-gloves.jpg` — suojakäsineet
- `photo-boxes.jpg` — muuttolaatikot

Firman omat oikeat kuvat: kansio `../own/`.
