## Kasvokuvista

Josua kysyi 24.8. ovatko pelkät naamakuvat myyviä. Oman tilin data sanoo ei:
elokuun ad-tason mittauksessa parhaat CTR:t (3,00–3,23 %) olivat mainoksissa
joissa oli tiiviste tai kynnys lähikuvana, ei asentajaa eikä taloa. Siksi
kasvokuvia on tässä paketissa enää yksi (`mainos-asentaja`) ja lähikuvia kaksi
(`mainos-veto`, `mainos-ovi`). Kasvokuva kannattaa pitää mukana yhtenä
testattavana kulmana — mutta se ei ansaitse olla paketin runko.

## URL-parametrit (kampanjan mittaus)

Jokaiseen **uuteen** mainokseen kuuluu Ads Managerin *URL-parametrit*-kenttään
(tai `publish.mjs`:n `URL_TAGS`-vakio, joka tekee sen automaattisesti):

```
utm_source=facebook&utm_medium=paid&utm_campaign={{campaign.name}}&utm_content={{ad.name}}
```

Ilman tätä sivusto tunnistaa `fbclid`istä että kävijä tuli Metasta ja kirjaa
kampanjaksi `meta-ads`, mutta **ei mistä mainoksesta** — kaikki Meta-liikenne
menee yhteen kasaan adminin "Kävijät kampanjoittain" -raportissa.

**Älä lisää tätä käynnissä olevaan mainokseen.** `url_tags` on osa creativea,
eikä olemassa olevaa creativea voi muokata: sekä Ads Manager että API luovat
muutoksesta uuden creativen, mikä nollaa oppimisvaiheen ja sotkee käynnissä olevan
split-testin. Nämä kahdeksan ovat uusia mainoksia, joten parametrit kuuluvat niihin
heti alusta.

## Renderöinti uudelleen

```
node tiiviskoti/mainokset/render.mjs all          # kaikki 8
node tiiviskoti/mainokset/render.mjs mainos-veto  # yksi
```

Ajetaan repon juuresta. Käyttää järjestelmän Google Chromea (`channel:'chrome'`),
koska Playwrightin oma chromium-lataus ei toimi tällä koneella.

Mainoskuvat ovat `mainokset/kuvat/` — omat rajaukset 4:5-kehykseen, eivät sivuston
kuvia. Kohde on rajattu kehyksen yläkolmannekseen, koska otsikko ja tekstit
peittävät alaosan.
